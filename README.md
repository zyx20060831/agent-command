# Agent Command：分层多智能体协作 Skill

把复杂任务交给一套职责明确的协作流程：指挥理解用户意图，执行负责拆分与汇总，工作智能体完成限定任务，独立审核检查成果，风格编辑改善表达。

```text
用户 ↔ 指挥
        ├─ 执行 ─┬─ 工作智能体 A
        │        ├─ 工作智能体 B
        │        └─ 工作智能体 C（按资源调度）
        ├─ 独立审核
        └─ 风格编辑
```

职责结构不代表所有角色必须同时运行。Skill 会根据宿主的并发限制分阶段调度，并披露角色合并或缺少独立审核的情况。它是一套可移植的指令，不会增加宿主的智能体容量或权限。

## 工作流程

1. 指挥把原始请求整理为详细任务书，展示关键假设及需要确认的问题。
2. 执行智能体理解任务书，划分边界与依赖，为每个工作智能体提供严格的输入输出契约。
3. 工作智能体返回成果、依据、假设、局限与交接说明；执行智能体检查并整合。
4. 独立审核提出有依据、可修复的问题，并复查修复结果。
5. 风格编辑按用户偏好去除套话、重复与机械表达，保留事实、引用与限定条件。
6. 审核检查润色后的最终版本，指挥验收并交付。

“去除 AI 痕迹”在这里指改善表达质量、贴近用户声音，不承诺规避检测，不编造个人经历。

## 安装与使用

克隆或下载本仓库，将包含 `SKILL.md` 的仓库根目录放到你的 Codex skills 目录，例如 `~/.codex/skills/agent-command`。在支持相同 Skill 格式的其他宿主中，请使用该宿主的安装方式。

示例提示词：

> 使用 $agent-command 帮我完成这项任务：[任务内容]。先给我扩展任务书，把真正影响结果的待确认项列出来。表达风格：[偏好]。交付物：[格式]。

需要可用的智能体委派能力才能实现真实的多智能体执行。无此能力时，Skill 要求明确披露，并提供单智能体替代流程。无需 API 密钥、脚本或额外依赖。
